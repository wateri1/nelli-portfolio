# 📸 Нелли Ферзаулина | Сайт-портфолио & SMM Ментор

> Премиальный сайт-портфолио профессионального фотографа, контент-продюсера и ментора по основам SMM (Казахстан: Алматы & Астана).

## ✨ Особенности
- **Дизайн**: Editorial Luxury & Modern Minimalist (шрифтовая пара Cormorant Garamond + Plus Jakarta Sans, архитектура double-bezel, глубокий ночной графит).
- **Интерактивная галерея**: Мультифото-слайдер для каждой съёмки с поддержкой клавиш клавиатуры, свайпов на смартфонах и переключением рубрик (*Бренды*, *Эксперты*, *Fashion*).
- **Разделение направлений**: Отдельные интерактивные вкладки для съёмок и для SMM-обучения с прозрачным прайсом в тенге (₸).
- **WhatsApp-first**: Заказ в один клик без бюрократии с автоматической генерацией готового сообщения.
- **Производительность**: Изображения оптимизированы в WebP, оценка LCP < 1.0s, чистый адаптивный код.
